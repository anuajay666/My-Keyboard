# Inkly

Inkly is a personal Android keyboard, a private fork of [HeliBoard](https://github.com/HeliBorg/HeliBoard)
(GPL-3.0). It keeps HeliBoard's typing engine, auto-correct, suggestions, themes and Malayalam layout.
Planned additions: Malayalam suggestions, and on-device AI writing tools (fix grammar, change tone).

- Licence: GNU GPL v3 (see `LICENSE`). HeliBoard's original notices are kept in `UPSTREAM-README.md`.
- Not affiliated with the HeliBoard project.
- Planning documents: `replica/`.
- Build: Codemagic (`codemagic.yaml`), debug APK.
